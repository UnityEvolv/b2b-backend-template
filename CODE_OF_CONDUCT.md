# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work and
not the person, and do not harass anyone. Everyone taking part in the project's
issues, pull requests and discussions is expected to follow it.

## Reporting

Report unacceptable behaviour to the maintainers privately through the contact
listed on the UnityEvolv GitHub organisation profile. Reports are handled in
confidence, and the maintainers will act as the Contributor Covenant's
enforcement guidelines describe.
